5天4晚 · 私人旅行

福建经典

厦门 → 鼓浪屿 → 福建土楼 → 泉州

五天时间，从厦门和鼓浪屿开始，走进福建土楼的山谷，再到泉州认识真正的闽南。

定制这条路线

五天，刚好认识福建的几种样子。

福建并不适合赶着玩。厦门适合慢慢开始，鼓浪屿值得留出完整的一天；离开海边往山里走，会看到福建完全不同的一面：土楼、村落和山谷里的生活。

到了泉州，福建的历史、闽南文化和当地人的日常又重新连在一起。这不是一条需要严格照着执行的路线，什么时候出发、在哪里多停留一天、住什么样的酒店，都可以根据你和家人的旅行方式重新安排。

五天路线

  1. 厦门
  2. 鼓浪屿
  3. 福建土楼
  4. 泉州
  5. 泉州 · 返程
DAY 01

抵达厦门，先慢下来。

抵达厦门后，我们会根据你的航班或高铁时间安排接站并前往酒店。第一天不会刻意塞满景点，尤其是带父母、孩子或经过长途飞行抵达的客人，先把旅行节奏慢下来通常会舒服很多。

如果抵达时间比较早，下午可以去海边走走，也可以从老城区开始认识厦门。抵达较晚就简单休息，把体力留给第二天。

住宿：厦门
DAY 02

把一天留给海岛和老街。

早餐后前往码头，乘轮渡去鼓浪屿。这里不需要赶着完成一张景点清单，比起在几个热门地点之间来回赶路，我们更建议把时间留给岛上的老建筑、小巷、海边和那些偶然遇见的小店。

下午或傍晚乘船返回厦门。如果还有精力，晚上继续在厦门吃饭、散步；家庭旅行也可以早点回酒店休息。

住宿：厦门
DAY 03

从海边，走进福建的山里。

早餐后离开厦门，私人用车前往福建土楼。随着城市逐渐退到身后，沿途会进入山区、村落和传统聚居区，旅行节奏也会和厦门完全不同。

这一天并不只是为了拍一张土楼照片。我们更希望给你留一点时间走进村子，看看建筑内部、周围的山谷，以及今天仍然生活在这里的人。

住宿：土楼周边或根据最终路线安排
